# Telegram-бот для командной работы

## Описание проекта

Telegram-бот для добавления задач в общий список, просмотра задач и экспорта данных в CSV.

Проект разработан на Python с использованием библиотеки aiogram и базы данных SQLite3.

## Возможности

- `/start` — запуск бота и приветствие пользователя.
- `/add` — добавление новой задачи.
- `/list` — просмотр всех задач.
- `/list_csv` — экспорт списка задач в CSV-файл.
- `/cancel` — отмена добавления задачи.
- `/status` — показать инструкцию по изменению статуса задачи.
- `/setstatus` — изменить статус задачи по её номеру.

## Используемые технологии

- Python
- aiogram 3
- SQLite3
- CSV
- python-dotenv

## Структура проекта

- `main.py` — запуск бота.
- `config.py` — загрузка настроек и токена.
- `database/db.py` — работа с базой данных.
- `handlers/tasks.py` — обработчики команд.
- `keyboards/main_menu.py` — клавиатура бота.
- `services/csv_export.py` — экспорт задач в CSV.
- `requirements.txt` — список зависимостей.
- `.env` — хранение токена бота.

## Установка и запуск

1. Установить зависимости:

   ```bash
   python -m pip install -r requirements.txt
   ```

2. Создать файл `.env` и добавить токен:

   ```text
   BOT_TOKEN=ваш_токен_от_BotFather
   ```

3. Запустить бота:

   ```bash
   python main.py
   ```

## База данных

Используется SQLite3. Задачи сохраняются в таблице `tasks`, содержащей поля:

- `id` — идентификатор задачи;
- `text` — текст задачи;
- `user` — автор задачи;
- `created_at` — дата и время создания.
- `status` — статус задачи (Новая, В работе, Выполнена);
- `category` — категория задачи (Работа, Учёба, Личное и другие).

## Безопасность

Не публикуйте токен Telegram-бота и не загружайте файл `.env` в публичный репозиторий GitHub.
